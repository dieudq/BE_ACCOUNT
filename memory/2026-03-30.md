## Workflow (Event-Driven)

**Luồng Tạm Ứng (Updated):**

```
1. ERP Quy trình approved
   ↓ (webhook POST)
   
2. /webhooks/erp/events receives payload
   ↓ (validate eventId, eventType)
   
3. ERPEventListenerService.processEvent()
   ↓ (check idempotency in botLog)
   
4. handlePaymentApproved():
   - Find or create Voucher (from ERP data if not found)
   - Create PhieuChi automatically
   - Lock Voucher (isLocked=true, lockedAt=now)
   - Log to BotLog (action: erp_payment_approved)
   - Send Telegram notification to ALLOWED_TELEGRAM_USERS
   
5. Return 200 OK with {voucherId, phieuChiId, phieuChiNumber}
```
