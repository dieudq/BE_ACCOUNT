### Debit/Credit Logic (Final)
```
Phát sinh Nợ (Debit column) = + (incoming/revenue)
Phát sinh Có (Credit column) = - (expense/outgoing)

Net = Debit - Credit

Example:
  Account 515.1 (Revenue):
    Debit: 1,000,000
    Credit: 0
    → +1,000,000 (revenue received)
    
  Account 635.2 (Expense):
    Debit: 0
    Credit: 500,000
    → -500,000 (expense paid)
```

### Grouping by Month (Multi-Month)
```
For each month (Jan-Dec):
  1. Find all GL transactions in that month
  2. Group by account code
  3. Sum Debit + Credit per account
  4. Map accounts → Categories
  5. Sum by category
  6. Fill category rows in corresponding month column
```
